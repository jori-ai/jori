Running in two minutes.

One line in Terminal. It installs whatever is missing, puts Jori on your Mac and opens a setup page in your browser.

curl -fsSL https://getjori.ai/install.sh | bash
Mac app

Download Jori.dmg, drag it to Applications and open it. It installs Jori, then lives in your menu bar.

Homebrew

brew trust jori-ai/tap
brew install jori-ai/tap/jori
then jori setup

npm

npm create jori

  1. Your Mac. Checks what Jori needs and installs what's missing.
  2. Claude. Sign in with the Claude subscription you already have.
  3. About you. Your name, email, city and time zone, filled in from this Mac. Fix what's wrong.
  4. Keep it running. One button. Jori starts now, at every login and after a crash, with a few starter jobs on.
  5. Reach you. Connect the Jori app, iMessage, WhatsApp, Slack or Gmail.

On a Mac mini or a VM, run the same line over SSH. Setup gives you a link to open from your own computer, over Tailscale or an SSH tunnel, and checks that the machine stays on by itself: automatic login, no sleep, back up after a power cut. Linux VMs work too, minus the Mac-only features. jori update keeps it current. Read the script before you run it.

Every feature is a plugin.

The core is small: memory, chat, the scheduler and the safety rails. Everything Jori does on top of that is a plugin you turn on, turn off or remove. Turn one off and everything it runs stops. Remove it and nothing else breaks.

# see what's on jori plugin list jori plugin enable flights jori plugin disable sleep # write your own jori plugin new tide-alert --schedule "0 7 * * *" jori plugin install https://github.com/you/your-plugin

Or flip them on the control room's Plugins page.

A plugin is one folder: a plugin.json that declares its commands, schedules, settings and the keys it needs, playbooks in plain Markdown, and its tests. Keep yours private in your own folder or share it as a git repo. Nothing outside a plugin points into it, and jori plugin check keeps it that way.
