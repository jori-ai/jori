Run Jori on a server you rent.

Jori needs a computer that stays on. If you don't want to keep your own Mac or PC running, rent a small one from a cloud provider. You paste a few lines when you create it, and the setup page opens in your browser. No terminal.

  1. Create an account with a cloud provider

    Any provider that offers Ubuntu 24.04 works. Two simple ones:

    • Hetzner Cloud: the cheapest. A server with 2 CPUs and 4 GB of memory (type CX22) is a few euros a month.
    • DigitalOcean: a Basic Droplet with 4 GB of memory.

    Pick at least 4 GB of memory. You pay the provider directly, by the hour, and can delete the server any time.

  2. Copy your setup lines

    They carry a private key made in this browser just now. It opens your setup page, so don't share it. This page remembers it, so you can come back.

  3. Create the server and paste them in

    • In the Hetzner Cloud console, open a project and press Add Server.
    • Image: Ubuntu 24.04. Type: CX22 (or bigger).
    • Leave networking as it is (a public IPv4 address).
    • Under Cloud config, paste your setup lines.
    • Press Create & Buy now, then copy the server's IPv4 address.
    • In DigitalOcean, press Create → Droplets.
    • Image: Ubuntu 24.04 (LTS). Size: Basic, 4 GB memory (or more).
    • Choose a password or SSH key (you won't need it, but DigitalOcean asks).
    • Open Advanced options, tick Add Initialization scripts, and paste your setup lines.
    • Press Create Droplet, then copy its ipv4 address.
    • Create an Ubuntu 24.04 server with 4 GB of memory and a public IPv4 address.
    • Paste your setup lines into its user data or cloud-init box.
    • Let web traffic in (ports 80 and 443) if the provider has a firewall.

  4. Open your setup page

    Paste the server's IPv4 address. Installing takes about ten minutes after the server starts; this page checks every few seconds and the button lights up when it's ready.

What the lines do

On the server's first start they run this script: it makes a jori user, runs the normal installer, and serves the setup page at https://<address>.sslip.io with a real certificate, behind your private key. When you press Finish on the setup page, the server stops answering on the internet. Jori then talks to your phone through your own Supabase project, not through the server's address.

What works on a server

Everything except the Mac-only features (iMessage, Notes, Photos, Find My), which need Jori on a Mac.

Something went wrong?

If the button never lights up after 20 minutes, delete the server and create it again with the same lines. Logs are on the server in /var/log/jori-cloud-init.log.
