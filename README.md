# Jori

**Jori is an open-source AI coworker.** Give it a role, the tools that role uses, and a manager to report to — it does the work, asks when it's unsure, and keeps a written record of everything it did.

> Status: pre-alpha. Name, domain and org are reserved; the code starts here.

## What Jori is

- **A worker, not a chatbot.** Jori owns recurring work end to end (triage, follow-ups, reports, data entry, ops checks) instead of answering one prompt at a time.
- **Open source and self-hostable.** Your data, your models, your infrastructure.
- **Accountable.** Every action is logged, reviewable and reversible where the underlying system allows it; risky actions wait for a human yes.
